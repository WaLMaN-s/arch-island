Semua yang kamu perlukan, di satu bilah.

Dirancang khusus untuk pengguna Arch Linux dan i3wm tanpa mengorbankan performa sistem.

🎛️

Control Center Lengkap

Kendalikan WiFi, Bluetooth, slider audio, mic, kecerahan layar (`brightnessctl`), serta eject USB drive langsung dari bilah atas.

🎵

MPRIS Player & Synced Lyrics

Terhubung otomatis ke Spotify, Firefox, MPV, atau VLC dengan lirik lagu sinkron (*timed LRC*) yang bergulir mengikuti detik lagu.

📝

TodoList & Pengingat 1 Jam

Catat tugas cepat saat ngoding. Tugas selesai dicoret hijau dan sistem otomatis mengirim notifikasi pengingat setiap 1 jam jika ada tugas pending.

🎓

Jadwal Kuliah & Notif H-1 Malam

Kelola jadwal mata kuliah mingguan dengan pengingat otomatis di malam hari (pukul 20:00) agar kamu selalu siap menyambut kelas besok.

⌨️

Navigasi Keyboard Penuh

Pindah menu dengan tombol panah keyboard (`←` dan `→`), terintegrasi mulus dengan layout tiling i3wm dan X11.

⚡

Ringan: Rust + Tauri + Svelte

Dikompilasi menggunakan binary native Rust dan Svelte 5 runes. Mengonsumsi RAM di bawah 40MB dan CPU mendekati 0% saat diam.

Pasang di Arch Linux Kamu

Jalankan satu baris perintah ini di terminal untuk langsung mengompilasi dan menjalankan.

git clone https://github.com/WaLMaN-s/arch-island.git && cd arch-island && npm run update
