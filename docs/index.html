Everything you glance at, in one place.

Arahkan kursor ke tepi atas layar untuk membuka notch. Pindahkan mouse dan notch akan meluncur kembali ke persembunyiannya.

🎛️

Control Center Lengkap

Kendalikan WiFi, Bluetooth, Microphone slider, Master Volume, Display Brightness (`brightnessctl`), dan eject USB drive langsung tanpa membuka terminal.

🎵

MPRIS & Synced Lyrics

Deteksi otomatis pemutar musik sistem (Spotify, Firefox, MPV). Dilengkapi lirik lagu sinkron (*timed LRC*) yang auto-scroll mengikuti detik lagu.

📝

TodoList & Pengingat 1 Jam

Scratchpad tugas cepat. Tugas selesai dicoret dengan warna hijau segar, dan sistem otomatis mengirimkan notifikasi desktop setiap 1 jam jika ada tugas pending.

🎓

Jadwal Kuliah & Notif H-1 Malam

Daftar mata kuliah mingguan dengan pengingat otomatis di malam hari (pukul 20:00). Dilengkapi tombol tambah, ubah, dan hapus jadwal sesuai kebutuhan.

⌨️

Navigasi Keyboard Cepat

Gunakan tombol panah keyboard (`←` dan `→`) untuk berpindah antar menu seketika. Terintegrasi mulus dengan alur kerja tiling window manager i3wm.

⏻

Menu Daya Cepat (Power)

Aksi cepat Lock Screen (`i3lock`), Suspend (`systemctl suspend`), Reboot, dan Shutdown dengan klik konfirmasi agar tidak terpencet tidak sengaja.

Pertanyaan Umum (FAQ)

Beberapa hal yang sering ditanyakan mengenai Arch-dinamic.

Apakah Arch-dinamic gratis dan open source?

Ya! Arch-dinamic 100% gratis dan open source di bawah lisensi MIT. Source code lengkap tersedia di GitHub.

Window manager apa saja yang didukung?

Arch-dinamic dioptimalkan khusus untuk i3wm (X11) dengan Picom compositor. Jendela otomatis diset sticky, floating, dan berada di lapisan paling atas.

Media player apa saja yang mendukung lirik sinkron?

Semua pemutar media Linux yang mengekspos standar MPRIS di D-Bus: Spotify, Firefox, Google Chrome, MPV, VLC, Amberol, dan lainnya.

Di mana tugas dan jadwal kuliah saya disimpan?

Semuanya disimpan secara offline di komputer lokal Anda (melalui storage lokal webview Tauri). Tidak ada server eksternal, akun, atau pelacak analitik.
